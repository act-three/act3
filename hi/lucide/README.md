SVG icons vendored unmodified from Lucide 1.27.0:
https://github.com/lucide-icons/lucide/tree/1.27.0/icons

`icons.zip` contains the SVG files at its root, compressed with Deflate.
To update, archive the SVG files from the upstream release's `icons/`
directory and copy its root `LICENSE` file here.
Only the ZIP archive is embedded in the binary.
